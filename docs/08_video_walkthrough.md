## บทพูดตัวอย่าง (Script Template)

### 1. แนะนำตัว & โจทย์ (0:00 - 0:45)
> "สวัสดีค่ะ ดิฉัน ชนาภา สดุดี ขอเสนอโปรเจกต์วิชา CN466 เรื่อง **AIoT Industrial Cold Chain & Sensitive Facility Monitor** ค่ะ  
> เราเลือกกลุ่มเป้าหมายเป็น **วิศวกรโรงงานและนักศึกษา** เพื่อสอนสร้างระบบเฝ้าระวังตู้แช่ยา/วัคซีน และห้อง Server โดยใช้บอร์ด **Cucumber RIS (ESP32-S2)** จริงร่วมกับ AI ครบวงจรทั้ง Predictive Analytics, Machine Learning บน Google Colab และ **Gemini 2.5 Flash** พร้อม **Safety Guardrails** ค่ะ"

### 2. Flow การสั่งงาน AI แบบมืออาชีพ (0:45 - 1:50)
> "ในขั้นตอนการพัฒนา เราไม่ได้สั่งให้ AI เขียนโค้ดสุ่มสี่สุ่มห้า แต่ใช้ Workflow แบบ `/grill-me` และ `/plan`:  
> 1. ให้ AI สแกนพอร์ต `COM6` และตรวจเครื่องก่อน ทำให้พบว่าบอร์ด Cucumber RIS ของเรามีเซ็นเซอร์ I2C ครบ 3 ตัวคือ **HTS221, BMP280 และ MPU6050** พร้อมไฟ **NeoPixel RGB LED**  
> 2. AI ถามคำถามทีละประเด็นเพื่อวางแผนร่วมกันจนได้เอกสาร **Implementation Plan** แล้วเราตรวจอนุมัติก่อนเริ่มเขียนโค้ดจริง  
> 3. ระหว่างพัฒนา เราตรวจและกำกับ AI ตลอด เช่น ปรับ UI Dashboard ให้แสดงวงกลม 5 ค่าและกราฟอ่านง่าย แก้สเปกเอกสารให้ตรงกับ **Gemini 2.5 Flash** ที่ใช้งานจริง และแยกข้อมูลสำคัญไว้ใน `secrets.h` กับ `.env` ไม่ให้หลุดขึ้น GitHub ค่ะ"

### 3. Flow การตรวจงานและ Verification กับ AI (1:50 - 3:00)
> "หลัง AI เขียนโค้ดและแฟลชเฟิร์มแวร์ PlatformIO ลงบอร์ด `COM6` เราตรวจงานด้วย 3 ด่าน:  
> - **ด่านฮาร์ดแวร์:** ตรวจ Serial Monitor ยืนยันว่าเจอ I2C ครบ 3 ชิป (`0x5F`, `0x68`, `0x76`) และส่งแพ็กเก็ตขึ้น `broker.emqx.io` ได้จริง  
> - **ด่าน Automated Unit & API Test:** รัน `test_ai_and_api.py` ตรวจสูตร Slope, Z-Score, ETTF, Shock Detection และ Safety Guardrails  
> - **ด่าน E2E Browser Test:** รัน Playwright ให้เปิดเบราว์เซอร์จริง กดสลับโหมด จำลองเหตุการณ์ คุยกับ AI Assistant และตรวจ console error จนผ่านทั้งหมดค่ะ"

### 4. สาธิตระบบทำงานจริง (3:00 - 4:30)
> *(เปิดหน้า Dashboard `http://127.0.0.1:5000/` + กล้องส่องบอร์ด Cucumber RIS)*  
> "บนหน้า Dashboard จะเห็น **วงกลม 5 ค่า** คือ อุณหภูมิ ความชื้น ความกดอากาศ แรงสั่นสะเทือน และคะแนนสุขภาพระบบ พร้อม **กราฟแนวโน้มที่มีแถบโซนปลอดภัยสีเขียว** และปุ่มควบคุมไฟสถานะบนบอร์ดผ่าน MQTT ค่ะ  
> ทีนี้ลองกด **จำลองคอมฯ ดับ** ในแถบด้านซ้าย — แถบสถานะจะเปลี่ยนเป็นสีแดง `CRITICAL` ทันที และส่งคำสั่งไปเปลี่ยนไฟบนบอร์ดเป็นสีแดง  
> จากนั้นเปิด **AI Assistant** มุมขวาล่าง แล้วลองพิมพ์คำสั่งเสี่ยงว่า `'ปิดไฟ'` — **AI Safety Guardrail** จะปฏิเสธเป็นภาษาไทยอย่างเข้าใจง่าย พร้อมขึ้นแถบเตือนความปลอดภัย และบันทึกลงตาราง **Audit Log** ด้วยป้ายสีแดง **`บล็อก`** ทันที เพื่อป้องกันไม่ให้ปิดไฟเตือนระหว่างเกิดเหตุวิกฤตค่ะ  
> นอกจากนี้ยังดูข้อมูลและเปิด **Mini App** ผ่าน Telegram `@Chanaps_Bot` ได้ด้วยค่ะ"

### 5. ปิดท้าย (4:30 - 5:00)
> "ข้อมูลทั้งหมดสามารถ **ส่งออกเป็นไฟล์ CSV** สำหรับงานตรวจสอบมาตรฐาน GMP/GDP มีโมเดล **Isolation Forest** บน Google Colab และ Deploy หน้าคู่มือพร้อม **Live MQTT Sandbox** ขึ้น GitHub Pages ให้อาจารย์และผู้เรียนทดลองใช้งานผ่านเบราว์เซอร์ได้ทันที ขอบคุณค่ะ"

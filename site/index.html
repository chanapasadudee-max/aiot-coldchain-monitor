    🏭 AIoT for Industry — ระบบเฝ้าระวังตู้แช่ยา & ห้อง Server¶

    แพลตฟอร์มการเรียนรู้และระบบ AIoT แบบสองทางระดับอุตสาหกรรม (Full-Stack Bidirectional AIoT)

    ผสานฮาร์ดแวร์จริง บอร์ด Cucumber RIS (ESP32-S2) อ่านเซ็นเซอร์พร้อมกัน 3 ชนิด (HTS221 + BMP280 + MPU6050) ควบคุมไฟ NeoPixel RGB LED ผ่าน MQTT สองทาง ขับเคลื่อนด้วย Triple-Layer Hybrid AI (Predictive Slope/Shock Engine + Local Ollama qwen2.5 Copilot + Deterministic Safety Guardrails + Google Colab) พร้อม UI ผ่าน Web Command Center & Telegram Mini App

    วิชา: CN466 Internet of Things & AI ผู้พัฒนา: ชนาภา สดุดี (6610680214) ทดลอง Live MQTT Sandbox →

    📐 แผนภาพสถาปัตยกรรมระบบ (System Architecture)¶

    Telemetry (บอร์ด → AI) Command (AI → บอร์ด) ผ่าน Guardrails WSS ตรงจากเบราว์เซอร์

    ESP32-S2 MCUอ่าน I2C → แพ็ก JSON → Publish
    NeoPixel RGB LEDActuator · GPIO 18
    Publish JSON Subscribe CMD

    TX · Telemetry…/telemetry บอร์ด → คลาวด์
    RX · Command…/cmd คลาวด์ → บอร์ด
    WebSocketพอร์ต 8084 สำหรับเบราว์เซอร์
    Telemetry Validated CMD

    REST API คำสั่งจากผู้ใช้ WSS :8084

    🎓 สำหรับผู้เรียน (Learner Track)¶

    บทที่ 01

    สถาปัตยกรรมระบบ AIoT

    Data Pipeline ระดับอุตสาหกรรมตั้งแต่เซ็นเซอร์ถึง AI และแอคชูเอเตอร์

     บทที่ 02

    บอร์ด Cucumber RIS & Multi-Sensor

    สแกน I2C (HTS221 + BMP280 + MPU6050) และคุมไฟ NeoPixel RGB LED

     บทที่ 03

    การสื่อสาร MQTT สองทาง

    การ Publish Telemetry และ Subscribe Command บน Public Broker EMQX

     บทที่ 04

    AI Anomaly & Google Colab

    Predictive Slope, Z-Score, ETTF และ Workshop เทรน Isolation Forest vs OC-SVM

     บทที่ 05

    UI, AI Copilot & Telegram Mini App

    แดชบอร์ด Command Center, แชตภาษาไทยคุมบอร์ดจริง และ Telegram Bot

     เล่นสด · ไม่ต้องติดตั้ง
